# Portfolio Roadmap

This workspace contains a glassmorphism portfolio concept built around your requested style:

- Color palette inspired by Signal Violet and Mist Gray
- Left-side navigation layout
- Serif typography with a clean, elegant presentation
- Social media icons and portfolio sections for Home, Projects, Services, About, and Contact

## Design Direction

1. Sidebar-first layout with profile block, links, and compact social icons.
2. Glassmorphism panels using translucent white surfaces, subtle borders, and soft blur.
3. Violet and neutral gray base palette to match the provided visual reference.
4. Serif navigation and headings for a premium editorial feel.
5. Clear content blocks for portfolio highlights, services, and contact details.

## Suggested Roadmap for the Live Website

1. Replace placeholder content with your real name, bio, and profile photo.
2. Update social profile links to your actual Facebook, Instagram, Threads, and LinkedIn pages.
3. Add your real project names, statuses, and service details.
4. Include your portfolio images or screenshots under each project card.
5. Connect the contact section to your preferred email or messaging platform.
6. Test responsive behavior on desktop, tablet, and mobile sizes.
7. Publish the portfolio and review adjustments based on final feedback.

## Files Included

- `index.html` — main portfolio structure and content
- `styles.css` — glassmorphism styling, layout, and responsive behavior

## How to Preview

Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

You can replace the placeholder text and avatar initials with your actual personal details to make this design feel fully custom to your brand.
